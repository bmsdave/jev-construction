# Phase 0: go / no-go (Building Control)

**Решение: NO-GO для схемы «Jev в центре» (BM25 → Jev rerank → Jev ответ). Точным судьёй оказался Claude.**

Вопрос: «Нужно ли уведомлять Building Control о работе и какой маршрут её подписывает?»
4 метки из Building Regulations 2010 (reg 3, 9, 12, Sch 2–4).

**Данные: 301 строка.**
- 213 строк = 141 строка реальной сметы + 72 синтетических примера; метки ставили мы, test = 64.
- **88 эталонных строк**, ответ по каждой прямо указан в авторитетном источнике: Planning Portal, legislation.gov.uk, LABC, Approved Documents, GOV.UK, 20 страниц councils, NICEIC, ECA, Gas Safe, HETAS, OFTEC. Все 56 URL открываются, три утверждения я сверил с текстом страниц.

| Арм | Эталонный набор (88) | Test (64) |
|---|---|---|
| A: Jev вслепую | 0.60 | 0.63 |
| B: Jev + 3 найденных пункта | 0.70 | 0.63 |
| C: ключевые слова | 0.69 | 0.83 |
| B*: Jev + правильные пункты (оракул) | 0.99 | 0.84 |
| **D: Claude + те же 3 пункта** | **0.98** (0.94–1.00) | **0.92** |
| **D: Claude вслепую** | **0.95** (0.91–0.99) | 0.88 |

- **Гейт для Jev не пройден:** на test B − C = −0.20; на эталоне B и C на равных (+0.01, CI включает ноль).
- **Claude — лучший эксперт:** на эталоне обходит и Jev, и ключевые слова на 27–28 п.п., CI выше нуля.
- **Ключевые слова были завышены нашими же метками:** 0.83 на test, но 0.69 на независимом эталоне.
- **Узкое место Jev — поиск пунктов:** с правильными пунктами Jev даёт 0.99, с найденными BM25 — 0.70. Бинарный вопрос «нужно ли уведомление вообще» Jev решает хорошо (AUC 0.97).
- **Гибрид (Jev, неуверенные строки → Claude):** почти не экономит вызовы — 61–78% строк уходят к Claude, а точность ниже, чем у одного Claude.

**Деньги:** $5.00 из $5. Jev — $0.08. Claude через OpenRouter — $4.93, все эти ответы выброшены: из‑за моей ошибки reasoning съедал лимит токенов и ответы приходили пустыми. Ошибку исправил и закрыл тестом, а самого судью прогнал субагентами Claude Code без оплаты API. Меток они не видели.

**Оговорки:** метки test и эталона тоже ставил Claude (эталон — по цитируемым страницам), поэтому судья-Claude может разделять наше прочтение правил. **Ваша проверка 30 строк по‑прежнему нужна:** `packs/building_control/bench/owner_spotcheck.csv`.

**Предложение по архитектуре продукта:**
1. Маршрут решает Claude с пунктами закона в контексте.
2. Детерминированный код и Jev — дешёвый предфильтр («нужно ли уведомление»), дубли, большие объёмы.
3. Каждая строка отчёта ссылается на пункт. Эталонный набор — регрессионный тест пака.
